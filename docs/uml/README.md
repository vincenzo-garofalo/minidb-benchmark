# Diagrammi UML

Questa cartella contiene i sorgenti PlantUML dei diagrammi.

## Contenuto

- `architecture.puml`: vista a componenti dell'intero progetto.
- `java-class-diagram.puml`: classi principali dell'implementazione Java.
- `python-class-diagram.puml`: classi e moduli principali dell'implementazione Python.
- `rust-structure-diagram.puml`: struttura a moduli, struct ed enum dell'implementazione Rust.
- `command-sequence.puml`: sequenza di esecuzione di un comando MiniDB.
- `benchmark-sequence.puml`: sequenza generale del benchmark.

I file `.puml` possono essere aperti ed esportati con un qualsiasi renderer PlantUML.
